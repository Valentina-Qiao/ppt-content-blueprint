# ppt-content-blueprint

幻灯片**内容层** Skill：把一份内容文档（论文、开题/结题报告、方案、汇报材料，md/word/pdf 等）拆成答辩或汇报用的**逐页内容蓝图**——讲几页、每页核心论点、要点取舍、并列/流程/因果/对照关系、卡片·图表·时间轴·加粗等表达元素、数据口径。

- 只负责内容结构与逻辑，**不绑定任何视觉模板，不写 HTML/CSS**。
- 产物是逐页蓝图，交给表现层 Skill 出 HTML/PDF。
- 核心铁律：只重组不阉割用户文案；并列模块之间禁因果箭头；一页一论点；数据必带来源年份口径。

## 目录

- `SKILL.md`：工作流、6 条铁律、逐页蓝图产物定义。
- `references/page-patterns.md`：13 类页型库、关系判定决策表与箭头规则、表达元素清单、密度控制。
- `references/blueprint-template.md`：蓝图字段 schema 与完整真实范例。
